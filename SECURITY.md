# Security Policy

This repository is a curated list of links and contains no application code that handles user data. The `scripts/` folder holds small validation tools used by CI.

## Reporting a vulnerability

If you find a security problem in the tooling, or a listed link that points to a malicious or phishing site, please **do not open a public issue**.

Report it privately through GitHub: **Security → Report a vulnerability** on this repository, or contact the maintainer, [Syed Muhammad Tayyab](https://github.com/Syed-Muhammad-Tayyab).

Please include the affected entry or file, and steps to reproduce if relevant. Malicious entries are removed as soon as they are confirmed.
