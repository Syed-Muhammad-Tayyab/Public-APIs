# Code of Conduct

We want this project to be a friendly, harassment-free space for everyone, regardless of experience level, background or identity.

## Our standards

- Be respectful and constructive in issues, pull requests and discussions
- Give and accept feedback graciously
- Focus on what is best for the community and the quality of the list
- No harassment, insults, discrimination or personal attacks
- No spam, and no promotional entries disguised as APIs

## Enforcement

Maintainers may edit, reject or remove comments, commits, issues and pull requests that violate this code, and may ban contributors who repeatedly do so. Report problems privately to the maintainer, [Syed Muhammad Tayyab](https://github.com/Syed-Muhammad-Tayyab), via GitHub.

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
